01 / SANDBOX TOOLS

接入任意语言的 Agent

创建 external 实验，使用返回的 toolBaseUrl 与 token 调用 charge / receipt。业务操作标识用于检测重复，幂等键用于阻止重复。

POST /api/runs
{
  "strategy": "external",
  "scenario": "lost-response"
}

POST {toolBaseUrl}/tools/charge
X-Lab-Token: {token}
{
  "operation": "order-1:charge",
  "idempotencyKey": "order-1:charge"
}
02 / PROCESS SUPERVISION

真实崩溃，真实重启

监督器将 LAB_URL、LAB_TOKEN 和 LAB_CONFIG 传给子进程。崩溃只作用于它启动的进程。

node src/cli.mjs supervise 
  --scenario process-crash 
  -- python examples/external_agent.py

接入现有 HTTP 工具

npm start -- --upstream http://127.0.0.1:8000

将工具地址指向 {toolBaseUrl}/proxy/原路径。代理仅观测传输，不能证明上游没有重复副作用。详见仓库 docs/ADAPTERS.md。
